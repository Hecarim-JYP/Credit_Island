# 📚 이수 퀘스트

과목(스테이지)을 탐험하며 강의(몬스터)를 **퀴즈 배틀**로 이겨 이수하고, 캐릭터를 키워 졸업하는 웹 RPG입니다.

## 실행

`index.html`을 더블클릭하면 브라우저에서 바로 실행됩니다. 서버나 빌드는 필요 없습니다.
(Chrome, Edge 최신 버전 권장)

## 조작

| 상황 | 키 |
|---|---|
| 필드 이동 | 방향키 또는 WASD |
| 상호작용 | 강의·상자·카페(☕)·표지판에 부딪히기 |
| 월드맵 (과목 선택) | Tab 또는 HUD의 🗺️ 버튼 |
| 메뉴 (상태·가방·업적·성적표) | M 또는 Esc |
| 답 고르기 | 1~4 또는 클릭 |
| 다음으로 | Enter 또는 Space |
| 아이템 | Q 형광펜 · W 패스권 · E 에너지 드링크 · R 초콜릿 |
| 역질문 채점 | O 맞았다 · X 틀렸다 |

## 게임 규칙

- **월드맵**: 섬 위에 8과목이 길로 이어져 있습니다. 과목을 눌러 들어가고, 필드에서 Tab으로 언제든 다시 열 수 있습니다.
- **탐험**: 각 과목 맵은 숲으로 나뉜 4개 구역(풀밭·강·숲·광장)으로 되어 있고, 흙길을 따라 강의 3개와 기말고사가 순서대로 있습니다. 강의를 이수하면 잠긴 문(🔒)이 열립니다. 상자에서 아이템을 얻고, ☕ 카페에서 집중력을 회복하고 저장합니다. 좌측 하단 미니맵에 강의(분홍·빨강 = 미이수, 초록 = 이수), 상자(노랑), 카페(분홍), 내 위치가 표시됩니다.
- **퀴즈 배틀**: 정답을 맞히면 강의의 진도가 오르고, 진도 100%가 되면 이수합니다. 오답이나 시간 초과는 집중력(HP)을 깎습니다. 집중력이 0이 되면 낙제합니다(잃는 것은 그 배틀의 진행뿐).
- **역질문 턴**: 3턴마다 내가 강의에게 문제를 냅니다. 쉬움·보통·어려움 카드 중 하나를 고르면 강의가 답하고, 그 답이 맞았는지 내가 채점합니다. 강의의 오답을 지적하면 진도가 크게 오릅니다.
- **콤보·보너스**: 연속 정답은 콤보(최대 +50%), 제한시간 절반 안에 맞히면 ×1.2, 가끔 치명타 ×1.5.
- **아이템** (배틀당 3개까지)

  | 아이템 | 효과 |
  |---|---|
  | 🖍️ 형광펜 | 오답 선택지 1개 제거 |
  | 🎫 패스권 | 이번 문제를 정답으로 처리 |
  | ⚡ 에너지 드링크 | 다음 정답의 진도 2배 |
  | 🍫 초콜릿 | 집중력 30 회복 |

- **성장과 보상**: 강의를 이수하면 성적(A+~D)에 따라 경험치와 아이템을 받습니다. 레벨이 오르면 집중력·지력·순발력이 오르고 집중력이 완전 회복됩니다. 기말고사를 통과하면 과목 이수 보상을 받고 다음 과목이 열립니다.
- **업적**: 12개 (숨은 업적 2개 포함). 메뉴의 🏆 탭에서 확인합니다.
- **저장**: 브라우저(localStorage)에 자동 저장됩니다. 타이틀에서 "이어하기"로 계속합니다.

## 과목 구성 (컴퓨터과학과 8과목)

게임을 시작하면 **수강신청** 화면에서 과목을 고릅니다. 과목마다 강의 3개와 기말고사가 있고, 8과목을 모두 이수하면 졸업입니다. ★가 많은 과목일수록 강의 레벨이 높습니다.

| 과목 | 난이도 | 문제 |
|---|---|---|
| 💻 컴퓨터의 이해 | ★ | 진법 변환·자료의 표현은 자동 생성, 하드웨어·소프트웨어 기초는 문제 은행 |
| 🔢 이산수학 | ★ | 집합·순열과 조합은 자동 생성, 명제 논리는 문제 은행 |
| 🌲 자료구조 | ★★ | 스택·큐 연산과 트리 순회는 자동 생성, 정렬·탐색과 시간복잡도는 문제 은행 |
| 🧩 C++ | ★★ | 문제 은행 |
| 🐚 UNIX시스템 | ★★ | 문제 은행 |
| ⚙️ 운영체제 | ★★★ | 문제 은행 |
| 🔤 프로그래밍언어론 | ★★★ | 문제 은행 |
| ☁️ 클라우드컴퓨팅 | ★★★★ | 문제 은행 |

자동 생성 문제는 매번 새로 만들어지고, 오답 선택지에는 실제로 자주 하는 실수(나머지를 거꾸로 읽기, 1의 보수에서 멈추기, 스택과 큐 혼동, 진부분집합 개수 등)가 들어갑니다. 문제 은행은 강의마다 12문제(쉬움 4, 보통 5, 어려움 3)이고, 모든 문제에 해설이 나옵니다. 과목 구성과 단원은 실제 교과과정을 참고해 만든 것이며, 공식 교육과정표와 다를 수 있습니다.

## 파일 구조

```
index.html          화면 구성
style.css           스타일
js/data.js          과목·강의·맵·아이템·업적 데이터, 문제 생성기
js/game.js          필드, 퀴즈 배틀, 성장, 업적, 저장
docs/DESIGN.md      설계 문서 (§0이 이번 구현 범위, §1 이후는 확장 비전)
tests/data.test.js  문제 생성기·맵 검증 (node tests/data.test.js)
tests/autoplay.html 브라우저 자동 플레이 테스트 (?run=full, ?run=walk)
```

## 디버그

주소 끝에 `?debug=1`을 붙이면 켜집니다.

- 필드: `L` 레벨 업, `N` 현재 과목 강의 전부 이수 처리
- 배틀: `K` 즉시 이수

## 사용 리소스

외부 이미지·라이브러리를 쓰지 않았습니다. 그래픽은 캔버스 도형, SVG, OS 기본 이모지로 그립니다. 폰트는 Google Fonts의 Jua(SIL Open Font License)를 불러오며, 오프라인이면 시스템 폰트로 대체됩니다.
